## About

I am a Computer Science and Electronics student at North-West University. My previous studies in Computer Science at the University of KwaZulu-Natal form part of my academic journey; I have not represented either course as a completed qualification.

My technical interests include Python, Java, C++, HTML, SQL, software development, data and graphic design. I use tools including Adobe Photoshop and Inkscape for creative work.

## Run the projects

Each project has its own README with setup instructions. Most projects use standard tools and local data. The weather project uses the free Open-Meteo API and needs an internet connection. The Java project uses Maven to download its SQLite JDBC dependency.
