# Creative Portfolio Website

A responsive, accessible portfolio website template for presenting original graphic-design work. Built with plain HTML, CSS and JavaScript—no build tools or framework required.

## Preview locally
Open `index.html` in a browser, or run:
```bash
python -m http.server 8000
```
Then visit http://localhost:8000.

## Personalise it
1. Replace the sample project cards in `index.html` with your own original design work.
2. Add exported portfolio images in an `assets/` folder and update each image path and alt text.
3. Update the email and social links in the contact section.
4. Keep client work private unless you have permission to publish it.

The current cards are explicitly labelled as sample placeholders and are not claimed as completed client commissions.
